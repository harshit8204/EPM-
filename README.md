# 📋 EPM — Employment Management System

A modern **Employment Management System** built with React, Vite, and Tailwind CSS. Designed to streamline employee data management with a fast, responsive web interface.

---

## 🚀 Tech Stack

| Technology | Purpose |
|------------|---------|
| ⚛️ React | UI Components & State Management |
| ⚡ Vite | Build Tool & Dev Server |
| 🎨 Tailwind CSS | Styling & Responsive Design |
| 🔍 ESLint | Code Quality & Linting |
| 📦 PostCSS | CSS Processing |

---

## ✨ Features

- 👥 Employee record management
- 📊 Dashboard overview
- 🔍 Search and filter employees
- 📱 Responsive design (mobile-friendly)
- ⚡ Fast performance with Vite HMR

## 🛠️ Getting Started

### Prerequisites

Make sure you have the following installed:
- [Node.js](https://nodejs.org/) (v16 or higher)
- npm or yarn

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/harshit8204/EPM-.git
   cd EPM-
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Open in browser**
   ```
   http://localhost:5173
   ```
